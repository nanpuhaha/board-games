# 01. Overview & Glossary — Splendor (Classic)

## 게임 목표
보석 토큰을 모아 개발 카드를 구매하고 영구 보석 보너스(할인 엔진)를 구축하여 귀족을 영입한다. 가장 먼저 **15점(기본 목표)** 이상에 도달해 마지막 라운드를 발동시키고, 라운드 종료 시 가장 높은 명성 점수를 얻은 플레이어가 승리한다.

## 기본 사양
- **인원**: 2–4인
- **보석 종류 (5색 + 황금)**: `diamond`, `sapphire`, `emerald`, `ruby`, `onyx` + 조커 `gold` ([`data/setup-tables.json`](../data/setup-tables.json))
- **개발 카드 (90장)**: 1단계 40장 / 2단계 30장 / 3단계 20장 ([`data/cards.json`](../data/cards.json))
- **귀족 타일 (10장 중 인원+1장 사용)**: 각 3점 ([`data/nobles.json`](../data/nobles.json))

## 핵심 용어 (Glossary)
- **마켓 (Market)**: 각 단계(1, 2, 3)별로 앞면 공개되어 있는 최대 4장의 개발 카드.
- **보너스 (Bonus)**: 구매한 개발 카드가 제공하는 영구 보석 할인. 향후 카드 구매 비용을 영구히 줄이며 귀족 방문 조건을 충족하는 데 사용된다.
- **예약 (Reserve)**: 마켓의 카드 또는 덱 맨 위 비공개 카드를 최대 3장까지 확보하는 행동. 은행에 `gold`가 남아 있으면 1개 획득한다.
- **비공개 예약 (`face_down: true`)**: 덱 맨 위에서 뽑아 예약한 카드. 본인만 카드 ID를 볼 수 있고 타인에게는 `tier`만 공개된다.
- **귀족 방문 (Noble Visit)**: 턴 종료 시 본인의 영구 보너스가 귀족의 요구 조건 이상이면 해당 귀족을 영입해 3점을 얻는다 (한 턴에 최대 1명).
